I'm a Computer Science student deeply interested in the unglamorous but critical layer of software — the systems that make everything else possible. Backend infrastructure, distributed coordination, and security primitives are where I spend most of my time.

My engineering philosophy is straightforward: build things that are correct first, then fast, then operationally sound. I'm skeptical of premature abstraction and deeply interested in how systems fail under pressure — which is when good design actually matters.

I gravitate toward problems that require thinking carefully about concurrency, consistency guarantees, network partitions, and failure modes. The intersection of AI tooling and systems engineering is where I see the most interesting unsolved work right now.

"Focused on building technically meaningful systems emphasizing scalability, reliability, and real-world utility — not demos that don't survive production."

Outside of engineering, I run Arch Linux as my daily driver, maintain a personal homelab for experimenting with infrastructure tooling, and write occasionally about systems design and backend patterns.

AI-Powered Codebase Intelligence Platform

In Development 2024 — present
AI Tooling / Backend
Python, TypeScript
10k+ file codebases
Active development

Overview

A semantic code analysis platform that ingests entire codebases, builds a rich knowledge graph, and exposes a query interface powered by LLMs. Designed to help engineering teams understand large codebases, trace data flows, and generate architecture documentation automatically.

Technical Architecture

  • Tree-sitter based AST parsing for multi-language symbol extraction and call graph construction
  • Embedding pipeline using OpenAI/local models, stored in Qdrant for semantic vector search
  • Knowledge graph layer (Neo4j) for tracking inter-module dependencies and data flows
  • FastAPI async backend with streaming SSE responses for real-time query progress
  • LangChain ReAct agent for multi-step reasoning over codebase context

Challenges Faced

The most significant challenge was building a chunking strategy that preserves semantic coherence — naive line-based chunking loses function boundaries and context. Developed a custom AST-aware chunker that respects scope boundaries and embeds rich metadata.

Distributed File Sync Engine

Active 2024
Distributed Systems
Go
Raft consensus
gRPC + TLS

Overview

A P2P file synchronization daemon that maintains strong consistency across nodes using a custom implementation of the Raft consensus protocol. Designed for homelab and small-team use cases where reliability and correctness matter more than cloud convenience.

Technical Architecture

  • Full Raft implementation (leader election, log replication, snapshotting, cluster membership changes)
  • Rolling hash-based delta sync — only changed file regions are transmitted over the wire
  • BadgerDB as the local state store for file metadata and sync state machine entries
  • Bidirectional gRPC streams with mutual TLS and certificate pinning
  • inotify-based file watcher daemon with debounced event coalescing

Challenges Faced

Implementing correct log compaction and snapshotting without losing committed entries took several iterations. The interaction between snapshot installation and concurrent client reads exposed edge cases in the reference Raft paper that required careful interpretation.

Secure Verification Infrastructure

Active 2024
Security / Cryptography
Rust, Python
ZK-SNARKs, WebAuthn
SIH Finalist Project

Overview

A zero-knowledge identity verification framework designed for institutional applications. Enables verifiers to confirm identity attributes without learning the underlying data. Implements selective disclosure proofs, hardware-backed device attestation via WebAuthn, and a tamper-evident audit ledger.

Technical Architecture

  • Groth16 ZK-SNARK circuits compiled via Circom for selective attribute disclosure
  • WebAuthn Level 3 for hardware-backed authenticator attestation (passkey support)
  • PostgreSQL + append-only audit log with HMAC-chain verification for tamper evidence
  • Rust verification backend with WASM-compiled circuit verifiers for edge deployments
  • Role-based credential scoping and delegation via capability tokens

Adaptive Quorum Sizing in Weakly-Connected Edge Consensus Clusters
Published
Devansh Sachdeva · Advisor: Prof. [Name] · ACM Student Research Competition 2024
This paper investigates the performance-consistency tradeoff in Raft-based consensus systems operating in edge environments with intermittent connectivity. We propose AQSC — an adaptive quorum sizing controller that dynamically adjusts quorum requirements based on a Bayesian estimate of partition probability derived from historical heartbeat response latencies. Empirical evaluation on a five-node Raspberry Pi cluster shows a 31% reduction in write-stall events with no observable consistency violations over 72 hours of stress testing.

Zero-Knowledge Selective Disclosure for Institutional Identity Verification: A Practical Framework
Under Review
Devansh Sachdeva · 2024
We present a practical framework for deploying ZK-SNARK based selective disclosure credentials in institutional environments where verifiers need to confirm specific attribute predicates (age ≥ 18, role ∈ {admin, reviewer}) without learning underlying credential data. The framework integrates with existing PKI infrastructure and WebAuthn authenticators, providing a path to deployment without requiring blockchain infrastructure. We detail circuit design tradeoffs and demonstrate sub-20ms verification latency on commodity hardware.

eBPF-Based Observability for Distributed Database Query Paths
Exploring
Devansh Sachdeva · 2025
An investigation into using eBPF kernel programs to trace database query execution paths at the syscall level, correlating kernel-observed I/O events with application-layer query spans. The goal is to build a zero-instrumentation query profiler that works without code changes to the database binary, usable across PostgreSQL, SQLite, and custom storage engines.
